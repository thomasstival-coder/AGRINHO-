# 🌱 Agrinho — Produzir hoje, preservar o amanhã

Site educacional sobre **agronegócio e sustentabilidade**, desenvolvido como trabalho de programação.

**Autora:** Caroline Boraczynski da Silva

---

## 📋 Sobre o projeto

O site aborda a importância do agronegócio, práticas sustentáveis no campo, tecnologias modernas, desafios ambientais e soluções para o futuro da produção agrícola.

**Slogan:** *Produzir hoje, preservar o amanhã*

### Pergunta norteadora

> O agronegócio pode crescer sem comprometer os recursos naturais ao adotar práticas sustentáveis e tecnologias modernas que aumentam a produtividade com menor impacto ambiental. Isso inclui o uso eficiente da água, energias renováveis, redução de emissões, preservação do solo e aplicação da agricultura de precisão. Assim, é possível equilibrar desenvolvimento econômico e preservação ambiental, garantindo recursos para as futuras gerações.

## 🚀 Como usar / Publicar no GitHub Pages

1. Crie um repositório no GitHub (ex: `agrinho-sustentabilidade`)
2. Faça upload dos arquivos (`index.html`, `styles.css`, `script.js`, `README.md`)
3. Vá em **Settings → Pages**
4. Em **Source**, escolha a branch `main` (ou `master`) e a pasta `/ (root)`
5. Salve e aguarde alguns minutos
6. Acesse: `https://seu-usuario.github.io/nome-do-repositorio`

### Teste local

Abra o arquivo `index.html` no navegador ou use um servidor local:

```bash
# Com Python
python -m http.server 8000

# Com Node (npx)
npx serve .
```
